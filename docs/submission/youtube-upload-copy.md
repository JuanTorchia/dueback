DueBack — Proof, Not Promises | All Things Agentic Hackathon 2026

## Description

DueBack is an autonomous follow-through agent that keeps a company promise open until verified
evidence matches the exact outcome a person approved.

In this live demo, Gemini extracts a typed Outcome Contract from a synthetic refund promise. The
person approves a narrow, versioned action boundary. Cloud Tasks and Firestore continue the work in
the background, DueBack rejects an acknowledgement that does not prove the outcome, and a
deterministic verifier accepts only matching signed evidence.

Built with Gemini 3.5 Flash on Vertex AI, Genkit, Cloud Run, Cloud Tasks, Firestore, Firebase
Authentication and Firebase Hosting.

Live app: https://bulbasour-503317.web.app/en
Source code: https://github.com/JuanTorchia/dueback

The demonstrated merchant is an isolated controlled sandbox, not a real retailer. Merchant
confirmation is not bank settlement. Gemini proposes structured facts but cannot authorize actions
or decide that a case is complete.

I created this video for the purpose of entering DueBack in the Google All Things Agentic Hackathon
2026, in the Taskmaster category, as an individual/hobbyist entrant.
