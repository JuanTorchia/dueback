# Hackathon Readiness Checklist: Multichannel Follow-Through

The requirement-by-requirement evidence audit is maintained in
[`completion-audit.md`](completion-audit.md). A checked implementation task does not override a
`PARTIAL` or `EXTERNAL` result in that audit.

- [ ] Gemini contribution is visible in initial and inbound extraction
- [ ] Genkit flow is real, typed and tool-less
- [ ] Cloud Run, Firestore and Cloud Tasks evidence appears in demo
- [ ] Sandbox remains reproducible and clearly labeled
- [ ] Email mode is labeled real only after outbound and inbound smoke gates
- [ ] Delivery and acknowledgement do not produce false `DONE`
- [ ] Retry/redeploy produces no duplicate logical send
- [ ] One user-return notification is visible after tab closure
- [ ] Public judge path requires no paid credential or personal data
- [ ] Four-minute video shows problem, approval, action, false-DONE, recovery and proof
- [ ] Architecture, README, quickstart, limitations and decision log match deployment
- [ ] Repository access, public video and Devpost submission are complete
